This is a game inspired by MADLIBS. The game revolves around a user changing , or "fusing" new words of different types into a pre-designed spooky story. The story
is locally generated by ollama using gemma 4:e4b, with a theme inspired by halloween. 
The game is written in python, using pygame and other libraries to help with text-to-speech, sys to exit the program etc. 

----------------- Game logic ------------------

The game begins with a story uniquely but not randomly generated by gemma each cycle of the game. This boots up the start of the game until the user is prompted for
different types of words. The user enters words of these given types and once every word is entered, all these inputs are collected, and fused into the story to 
build a funny spin off of the model's original story!
